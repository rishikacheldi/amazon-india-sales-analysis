# Amazon India Sales Analysis Dashboard

An interactive **Power BI sales analytics project** exploring sales performance, profitability, product categories, payment methods, and monthly trends.

## Dashboard Preview

![Amazon India Sales Dashboard](screenshots/Screenshot%202026-09-29%20212806.png)

## Project Overview

This project analyzes Amazon India sales data using Microsoft Power BI and Excel. The dashboard brings key business metrics and sales patterns into a single visual report to support data-driven decision-making.

## Key Performance Indicators

The current dashboard displays the following figures:

| Metric | Dashboard Value |
|---|---:|
| Total Sales | 155.79M |
| Total Profit | 33.17M |
| Profit Margin | 21.29% |

*Figures are transcribed from the dashboard preview and should be validated against the underlying dataset before being treated as final results.*

## Dashboard Features

- **Sales and Profitability:** Track total sales, profit, and profit margin.
- **Monthly Trends:** Compare monthly sales and profit performance.
- **Product Analysis:** Identify products contributing to sales.
- **Category Analysis:** Compare sales and quantity across product categories.
- **Payment Analysis:** Examine sales across payment methods.
- **Order Analysis:** Review order counts and sales performance.
