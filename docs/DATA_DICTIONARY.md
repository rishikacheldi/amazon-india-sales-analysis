# Data Dictionary

## Overview

This document describes the fields used in the Amazon India Sales Analysis project.

| Column | Description | Data Type |
|---|---|---|
| Order ID | Unique identifier for an order, if applicable | Text |
| Date | Date associated with the order | Date |
| Amount | Sales amount recorded in the dataset | Numeric |
| Qty | Quantity of items | Numeric |
| Category | Product category | Text |
| Status | Order or shipment status | Text |
| Fulfillment | Fulfillment method | Text |
| ship-state | Shipping state, if available | Text |
| Payment Method | Payment method, if available | Text |

**Note:** Verify each column name and meaning against the actual Excel dataset before finalizing this dictionary. Remove fields that are not present.
